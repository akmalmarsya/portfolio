Tentang Saya

Fokus pada Alur Logika & Struktur Data

Ketertarikan saya di bidang software engineering bermula dari rasa penasaran tentang bagaimana sebuah sistem bekerja di balik layar. Mulai dari bagaimana skema database dimodelkan, bagaimana logika bisnis diproses, sampai bagaimana data dikirimkan lewat endpoint API secara aman. Saat ini, saya sedang menempuh studi D4 Teknik Informatika di Politeknik Elektronika Negeri Surabaya (PENS) angkatan 2025 (saat ini semester 3).

Dalam mengerjakan proyek, saya terbiasa menggunakan PHP (Laravel dan PHP Native) serta Python. Untuk basis data, saya rutin memakai MySQL dan PostgreSQL. Selain memperdalam backend, saya juga antusias mengeksplorasi integrasi AI ke dalam aplikasi web.
